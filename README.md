# Reproducible Research: Activity Monitoring Analysis

Built as part of the **Reproducible Research** course (project 1) in the **Johns Hopkins Data Science Specialization** (Coursera), 2024. This is a fork of rdpeng's template with completed analysis.

## What's inside

- PA1_template.Rmd: R Markdown analysis of personal activity monitoring data with mean/median daily steps, activity patterns, and imputation of missing values
- PA1_template.md: Markdown output of the analysis
- PA1_template.html: HTML compiled version with figures
- activity.csv: Activity monitoring dataset with steps recorded at 5-minute intervals
- figure/: Generated plots showing step patterns

## Notes

Analyzes activity data from October-November 2012, examining daily step totals, activity patterns by time of day, missing data imputation, and weekday vs. weekend patterns. Render with `knitr::knit2html()` to regenerate outputs.
